# NEXUS CONF — лабораторная работа № 5

React-приложение лендинга IT-конференции с глобальным управлением избранными спикерами через Redux Toolkit.

## Реализовано

- `favoritesSlice` хранит массив идентификаторов избранных спикеров.
- Действие `toggleFavorite` добавляет или удаляет ID спикера.
- Действие `clearFavorites` очищает список.
- `SpeakerCard` использует `useSelector` и `useDispatch` для работы со store.
- `Favorites` независимо подписывается на store, показывает количество и выбранных спикеров.
- Корневой компонент обернут в `<Provider store={store}>`.
- Состояние синхронизируется без прямого взаимодействия компонентов.

## Запуск

Требуется Node.js и npm.

```bash
npm install
npm run dev
```

Откройте адрес, который Vite выведет в терминале, обычно `http://localhost:5173`.

## Проверка сборки

```bash
npm run build
```

## Демонстрация

1. Откройте раздел со спикерами.
2. Нажмите «Добавить в избранное» на любой карточке.
3. Убедитесь, что счетчик и список в блоке «Избранные спикеры» обновились одновременно.
4. Повторно нажмите кнопку карточки — спикер будет удален.
5. Добавьте несколько спикеров и нажмите «Очистить».
